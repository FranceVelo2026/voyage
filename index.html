🚴 Dupliquer un itinéraire dans RideWithGPS sur iPad
  1. Ouvrir Bibliothèque, puis Itinéraires.
  2. Ouvrir l’itinéraire à dupliquer.
  3. Toucher Planifier au bas de l’écran.
  4. Dans le planificateur, toucher Terminé, sans modifier le tracé.
  5. Toucher Enregistrer.
  6. Choisir Enregistrer comme nouveau (Save as New).
  7. Donner un nouveau nom à la copie, puis enregistrer.

La copie peut ensuite être modifiée sans toucher à l’itinéraire original.

📲 Mise à jour du site sur GitHub — tablette
  1. Télécharger le fichier France2026_vX.X.X.zip depuis ChatGPT.
  2. Dans Fichiers > Téléchargements, toucher le ZIP pour le décompresser.
  3. Dans Safari, ouvrir le dépôt FranceVelo2026 sur GitHub.
  4. Choisir Add file > Upload files.
  5. Sélectionner tout le contenu du dossier décompressé, et non le dossier lui-même.
  6. Attendre la fin du téléversement, inscrire « Mise à jour vX.X.X », puis toucher Commit changes.
  7. Après environ une minute, rouvrir le site et vérifier le numéro de version dans Informations.

Si l’ancienne version reste affichée, fermer le site puis le rouvrir dans Safari.
